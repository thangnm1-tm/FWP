# Repository Instructions

## Mobile / Frontend UI

Before writing or changing code that affects the mobile app or frontend UI, consult the current UI/UX conventions provided by `npx ui-skills` and apply the relevant guidance.

- Do this automatically for each such request, before editing UI code; do not wait for the user to remind you.
- First inspect the available `ui-skills` CLI usage/documentation, then use its appropriate command to load relevant rules. Do not assume CLI syntax or invent subcommands.
- If the package cannot be fetched or run (for example, network access is unavailable), report that limitation and continue using the project's existing design system, clearly noting the fallback.
- Apply this to Android/Compose and web frontend work, including visual changes and new UI components; it does not apply to backend-only changes.
